# Описание

Исходники находятся в папке src. `compose.yaml` - это compose проект с новыми сервисами бронирования и статистики, а также их инфраструктурой. При этом каждый из сервисов имеет свою СУБД в отдельном контейнере и отдельную инфраструктурную сеть под них. Кроме того в проект включены два сервиса-мигратора, которые по сути являются Entity Framework Core Migration бандлами. Сервис с историей называется `booking-statistics` и обладает своим небольшим апи, которое позволяет получать все бронирования и бронирования по конкретным пользователям.

Измененные тесты находятся в папке test. Оттуда убран тест на получение всех бронирований, так как он не работал на уровне монолита из-за неверной работы с пустыми значениями. При этом тесты на получение бронирований по конкретным пользователям проходят. В новом сервисе бронирования на всяких случай предусматривается возможность получения всех бронирований без указания пользователя. Кроме того, вынесен скрипт создания фикстур под сервис бронирования `init-fixtures-booking.sql` и соответствующим образом обновлен `regress.sh`. Также добавлены два простых теста для сервиса статистики.

Для запуска проекта требуется чтобы предварительно был запущен compose проект из директории выше (`docker-compose.yml`). После этого в текущей директории следует выполнить `docker compose up -d --build`. Дополнительных действий не требуется, все миграции и создание топиков происходят в процессе запуска.

Чтобы запустить обновленные тесты, после запуска проекта выполните:

```sh
docker run --rm -e DB_HOST=host.docker.internal -e DB_PORT=5432 -e DB_NAME=hotelio -e DB_USER=hotelio -e DB_PASSWORD=hotelio -e BOOKING_DB_HOST=host.docker.internal -e BOOKING_DB_PORT=5433 -e BOOKING_DB_NAME=booking-db -e BOOKING_DB_USER=booking -e BOOKING_DB_PASSWORD=booking -e API_URL=http://host.docker.internal:8084 -e STATISTICS_API=http://host.docker.internal:9091 hotelio-tester
```
