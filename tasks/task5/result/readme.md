# Описание

Helm чарт сервиса бронирования переделан под два темплейта деплойментов: v1 и v2. В качестве feature флага используется `X-KafkaPublish-Enabled`, по этому же заголовку трафик перенаправляется на v2. Стоит только заметить, что это делается не с помощью envoy filter, а с помощью match headers в virtualservice. Также в destination rule не удалось настроить retry (как по заданию), но он вполне себе прижился в virtual service.

В проверке канареечного тестирования вместо логов приложен скриншот из Kiali, который показывает в процентах, в какой сабсет сколько процентов трафика уходило.
